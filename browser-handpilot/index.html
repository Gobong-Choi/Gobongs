브라우저파일럿BROWSER HAND-PILOT

사용자가 채팅창에서 "크롬으로 구글에서 ○○ 검색해줘"라고 시키면, Claude가 평소 크롬과 별도로 실행되는 Claude 작업용 크롬에서 탭 화면 사진을 보고 그 탭 안에서만 클릭하고 입력합니다. Claude는 웹페이지 코드를 읽지 않고, 진짜 마우스·키보드도 움직이지 않아서 사용자는 그동안 다른 창을 그대로 쓸 수 있습니다.

📸

사람처럼 보고 누르기

Claude가 탭 화면 사진만 보고 누를 위치를 정합니다. 웹페이지 코드는 읽지 않고, 누른 뒤에는 화면 변화가 끝나면 다시 사진을 받아 결과를 확인합니다.

🗂️

탭 안에서만

클릭·입력은 그 탭에만 들어갑니다. 진짜 마우스·키보드는 그대로라 사용자가 하던 다른 창 작업에 영향이 없습니다.

🕶️

따로 실행되는 Claude 작업용 크롬

Claude가 평소 크롬과 별도로 실행되는 크롬 창을 화면 오른쪽 아래에 띄우고, 그 안의 시크릿 창(방문 기록이 남지 않는 창)에서 일합니다. 이 창은 다른 창 뒤에 가려져도 됩니다. 평소 사용하는 크롬(로그인된 계정)은 사용자가 "평소 크롬으로 해줘"라고 할 때만, Claude가 한 번 확인한 뒤 씁니다.

🏷️

채팅마다 탭 그룹

Claude가 연 탭은 "BrowserPilot 1" 같은 이름의 탭 그룹(크롬의 탭 묶음, 채팅마다 색이 다름)에 모이고, 확장 프로그램 아이콘에 "AI1" 같은 표시가 붙습니다. 크롬은 Claude 채팅 4개까지 동시에 쓸 수 있고, Claude는 다른 채팅의 탭을 건드리지 않습니다.

🧅

Tor 브라우저도

Claude가 Tor 브라우저도 같은 방식으로 조작합니다(한 번에 한 채팅). Tor 브라우저가 꺼져 있으면 Claude가 띄웁니다.

🔐

안전 장치

Claude 쪽 프로그램과 크롬 확장 프로그램은 컴퓨터마다 따로 만드는 비밀 암호로 서로 확인합니다. 웹페이지는 이 연결에 끼어들 수 없습니다. 로그인·결제·다운로드는 Claude가 먼저 사용자에게 묻습니다.

설치 파일이 막힐 때 (스마트 앱 컨트롤)

Windows 11에서 "스마트 앱 컨트롤이 … 차단했습니다"가 나오면 스마트 앱 컨트롤은 끄지 마세요(끄면 Windows를 새로 설치하기 전에는 다시 못 켭니다). 대신 사용자가 시작 메뉴에서 PowerShell을 열고(Claude 앱 안이 아닌 일반 창, 관리자 권한 불필요) 아래 한 줄을 붙여 넣고 Enter를 누르세요. 설치 파일과 똑같이 진행됩니다.

$f="$env:TEMP\browser-handpilot-setup.ps1"; iwr -UseBasicParsing https://gobong-choi.github.io/Gobongs/browser-handpilot/setup.ps1 -OutFile $f; powershell -NoProfile -ExecutionPolicy Bypass -File $f

무엇을 하는지 먼저 보고 싶으면 setup.ps1을 열어 보세요. 끝나면 아래 2단계(Claude 작업용 크롬에 확장 프로그램 올리기)부터 이어서 합니다.

  1. 설치 파일 받기 → 더블클릭

    설치 파일이 Claude 앱 확인 → Node.js(없으면 설치) → 설치용 zip 내려받기 → 사용자 폴더\BrowserHandPilot에 크롬 확장 프로그램·설정·비밀 암호 만들기 → Claude 앱에 플러그인 등록까지 자동으로 합니다. 끝나면 확장 프로그램 폴더가 열립니다.

    ⚠️
    처음 보는 파일이라 경고가 나올 수 있습니다. 브라우저가 묻으면 [유지], 파란 "Windows의 PC 보호" 창이면 [추가 정보] → [실행]을 누르세요.

  2. Claude 작업용 크롬에 확장 프로그램 올리기 (처음 한 번)

    ① 사용자가 Claude 앱에서 새 채팅을 열고 "크롬으로 구글 열어줘"라고 말합니다. 권한 요청 창이 뜨면 허용하세요.

    ② Claude가 화면 오른쪽 아래에 Claude 작업용 크롬 창(북마크·로그인이 없는 새 크롬 창, 첫 탭 제목 "브라우저파일럿 전용 크롬")을 띄우고, 그 창에 확장 프로그램 관리 화면(chrome://extensions)을 엽니다. 평소 사용하는 크롬에는 아무것도 열리지 않습니다.

    ③ 사용자가 그 Claude 작업용 크롬 창에서 오른쪽 위 개발자 모드를 켜고, 압축해제된 확장 프로그램을 로드합니다를 눌러 사용자 폴더\BrowserHandPilot\extension 폴더를 고릅니다. 카드의 ID가 kheofijbolmhdnfmplopdgkfcfbmkohn이면 맞습니다.

  3. 시크릿 모드 허용

    사용자가 같은 Claude 작업용 크롬 창에서 브라우저파일럿 확장 프로그램 카드의 세부정보를 열고 시크릿 모드에서 허용을 켭니다.

  4. 확인

    사용자가 채팅에서 다시 "크롬으로 구글 열어줘"라고 말합니다. Claude가 Claude 작업용 크롬에 "BrowserPilot 1" 같은 이름의 탭 그룹을 만들고 구글 화면 사진을 보여 주면 성공입니다.

    (선택) 평소 사용하는 크롬에 로그인된 상태로도 일을 시키려면, 사용자가 평소 사용하는 크롬에서도 2~3단계의 확장 프로그램 올리기를 똑같이 합니다.

4사용법
사용자가 채팅창에서 말로 시키면 됩니다.

작업 중에는

  • 이 PC에 Claude in Chrome(Anthropic이 만든 크롬 확장 프로그램)이 있으면 Claude는 그것을 먼저 씁니다. 연결이 안 되거나 그 사이트에서 막히면, 또는 사용자가 "브라우저파일럿으로", "기록 안 남게"라고 말하면 Claude가 한 줄로 알리고 브라우저파일럿으로 바꿉니다.
  • Claude가 조작하는 크롬 창 위쪽에 크롬의 "디버깅을 시작함" 노란 안내 줄이 뜹니다. 정상입니다(보통은 Claude 작업용 크롬에만 뜹니다).
  • Claude가 연 탭은 "BrowserPilot 1" 같은 탭 그룹에 모입니다. 평소 사용하는 크롬의 탭은 그대로입니다.
  • Claude 작업용 크롬 창은 다른 창 뒤에 가려져도 됩니다. 최소화되면 Claude가 원래 크기로 되돌립니다.
  • 로그인이 필요한 사이트는 사용자가 Claude 작업용 크롬의 일반 창(시크릿 창이 아닌 창)에서 한 번 직접 로그인해 두면, Claude가 그 로그인 상태를 씁니다.
  • 네이버 등 일부 사이트는 Tor 브라우저 접속을 막습니다. 그때는 크롬으로 시키세요.
⚠️
Claude가 보는 탭 사진은 Claude(Anthropic)로 전송됩니다. 평소 사용하는 크롬을 쓰면 로그인된 계정 정보가 사진에 찍힐 수 있으니 필요할 때만 쓰세요.
5업데이트
사용자가 같은 설치 파일을 다시 더블클릭하면 됩니다. 설정과 비밀 암호는 그대로 두고 코드만 새것으로 바꿉니다.

0.8 이상은 다음에 Claude가 크롬을 쓸 때 확장 프로그램이 스스로 새 버전을 불러옵니다. 0.7에서 올리는 경우에만 사용자가 설치 2~3단계(Claude 작업용 크롬에 확장 프로그램 올리기·시크릿 모드 허용)를 한 번 합니다.

6문제 해결
"전용 크롬에 브라우저파일럿 확장이 연결되지 않았습니다"설치 2~3단계(Claude 작업용 크롬 창에 확장 프로그램 올리기)를 하세요. 이미 했으면 그 창의 확장 프로그램 카드에서 새로고침을 누르세요.
"사용자 크롬에 브라우저파일럿 확장이 연결되지 않았습니다"평소 사용하는 크롬이 켜져 있는지, 거기에 확장 프로그램이 올라가 있는지 확인하세요.
크롬(chrome.exe)을 찾지 못했다는 문구시작 메뉴 브라우저파일럿 관리 → 설정의 '크롬 위치'에 chrome.exe 위치를 적으세요.
"비밀 암호 파일이 없습니다"설치 파일을 다시 실행한 뒤 확장 프로그램 카드에서 새로고침을 누르세요.
"시크릿 모드가 허용되지 않았습니다"설치 3단계(시크릿 모드 허용)를 하세요.
"이미 설치됨" / 확장 프로그램을 못 올림같은 확장 프로그램이 이미 올라가 있으면 먼저 삭제하세요. 개발자 모드가 회사 정책으로 막혔다면 쓸 수 없습니다.
Tor 브라우저를 못 찾음시작 메뉴 브라우저파일럿 관리 → 설정에 Tor 브라우저 폴더 안의 Browser\firefox.exe 위치를 적으세요.
확장 프로그램 오류 목록의 ERR_CONNECTION_REFUSEDClaude 채팅이 크롬 기능을 쓰고 있지 않을 때 나는 정상 기록입니다.
