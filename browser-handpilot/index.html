사람처럼 보고 누르기

탭 사진만 보고 위치를 정합니다. 웹페이지 코드를 읽지 않고, 동작 뒤에는 화면이 멈춘 다음의 사진을 받아 결과를 확인합니다.

🗂️

탭 안에서만

그 탭에만 클릭·입력이 들어갑니다. 진짜 마우스·키보드는 그대로라 다른 창 작업에 영향이 없습니다.

🕶️

크롬은 기본 시크릿

시크릿 창에서 작업합니다. 로그인된 일반 크롬은 "일반 크롬으로 해줘"라고 할 때만, 한 번 확인한 뒤 씁니다.

🏷️

채팅마다 탭 그룹

Claude가 조작하는 탭은 "Hand-pilot N" 탭 그룹(색 구분)과 "AI N" 배지가 붙습니다. 크롬은 채팅 4개까지 동시에, 다른 채팅의 탭은 건드리지 않습니다.

🧅

토르도

토르 브라우저도 같은 방식으로 조작합니다(한 번에 한 채팅). 꺼져 있으면 Claude가 띄웁니다.

🔐

안전 장치

도구와 확장은 컴퓨터마다 따로 만드는 비밀 암호로 서로 확인합니다. 웹페이지는 도구에 접속할 수 없습니다. 로그인·결제·다운로드는 먼저 묻습니다.

2준비물
Windows PC 한 대마다 한 번씩 설치합니다.
Windows 10 / 11Mac은 지원하지 않습니다.
Claude 데스크톱 앱직접앱을 설치하고 Code 탭을 한 번 열어 두세요.
크롬직접확장을 올릴 때 개발자 모드를 켭니다(회사 정책으로 막힌 PC는 설치 불가).
Node.js자동없으면 설치 파일이 설치합니다(Windows가 권한을 물으면 [예]).
Tor Browser선택토르를 쓸 때만. 바탕화면 등에 있으면 자동으로 찾습니다.
3설치
설치 파일을 받아 더블클릭한 뒤, 크롬에 확장을 한 번 올리면 끝입니다.
⬇설치 파일 받기
브라우저핸드파일럿-설치.cmd (1KB) — 받은 파일을 더블클릭하세요.
① 받기② 더블클릭③ 크롬에 확장 올리기④ 시크릿 허용

  1. 설치 파일 받기 → 더블클릭

    Claude 앱 확인 → Node.js(없으면 설치) → 묶음 내려받기 → 사용자 폴더\BrowserHandPilot에 확장·설정·비밀 암호 만들기 → Claude Code에 플러그인 등록까지 자동으로 합니다. 끝나면 확장 폴더가 열립니다.

    ⚠️
    처음 보는 파일이라 경고가 나올 수 있습니다. 브라우저가 묻으면 [유지], 파란 "Windows의 PC 보호" 창이면 [추가 정보] → [실행]을 누르세요.

  2. 크롬에 확장 올리기 (처음 한 번)

    크롬 주소창에 아래를 넣고 오른쪽 위 개발자 모드를 켭니다. 압축해제된 확장 프로그램을 로드합니다 → 사용자 폴더\BrowserHandPilot\extension을 고릅니다.

    chrome://extensions

    카드의 ID가 kheofijbolmhdnfmplopdgkfcfbmkohn이면 맞습니다.

  3. 시크릿 모드 허용

    확장 카드의 세부정보 → 시크릿 모드에서 허용을 켭니다.

  4. 확인

    Claude 앱에서 새 채팅을 열고 "크롬 탭 목록 보여줘"라고 합니다. 도구 허용 창이 뜨면 허용하세요. 첫 줄에 이 채팅의 탭 그룹: Hand-pilot N이 나오면 성공입니다.

작업 중에는

  • 조작하는 탭 위에 크롬의 "디버깅 중" 노란 띠가 뜹니다. 정상입니다.
  • Claude 탭은 Hand-pilot N 그룹에 모입니다. 내 탭은 그대로입니다.
  • 네이버 등 일부 사이트는 토르 접속을 막습니다. 그때는 크롬으로 시키세요.
⚠️
Claude가 보는 탭 사진은 Claude(Anthropic)로 전송됩니다. 일반 크롬은 로그인된 계정 정보가 사진에 찍힐 수 있으니 필요할 때만 쓰세요.
5업데이트
같은 설치 파일을 다시 더블클릭하면 됩니다. 설정과 비밀 암호는 그대로 두고 코드만 새것으로 바꿉니다.

업데이트 뒤에는 크롬 확장 카드의 새로고침(↻)을 눌러 주세요.

6문제 해결
"크롬 확장프로그램이 연결되지 않았습니다"크롬이 켜져 있는지, 확장이 켜져 있는지 확인하고 확장 카드의 새로고침을 누르세요.
"비밀 암호 파일이 없습니다"설치 파일을 다시 실행한 뒤 확장을 새로고침하세요.
"시크릿 모드가 허용되지 않았습니다"설치 3단계(시크릿 모드 허용)를 하세요.
"이미 설치됨" / 확장을 못 올림같은 확장이 이미 올라가 있으면 먼저 삭제하세요. 개발자 모드가 회사 정책으로 막혔다면 쓸 수 없습니다.
토르를 못 찾음사용자 폴더\BrowserHandPilot\config.json의 torExe에 토르 폴더의 Browser\firefox.exe 경로를 적으세요.
확장 오류 목록의 ERR_CONNECTION_REFUSEDClaude 도구가 꺼져 있을 때 나는 정상 기록입니다.
