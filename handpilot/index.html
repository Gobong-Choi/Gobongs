👀

보고, 누르고, 입력

스크린샷으로 화면을 보고 클릭·드래그·글자 입력·단축키·스크롤을 합니다. 작은 글씨는 확대(zoom)해서 읽습니다.

🪶

바뀐 부분만 보내기

동작 후 화면이 멈출 때까지 기다렸다가 바뀐 부분만 잘라 보냅니다. 매번 전체 화면을 보낼 때보다 이미지 토큰이 크게 줄어듭니다.

✋

만지면 바로 멈춤

작업 중에 내가 마우스나 키보드를 만지면 즉시 일시정지. 화면 구석 표시창에서 [재개] 또는 [종료]를 누릅니다.

🔒

한 번에 한 채팅창만

여러 채팅창이 동시에 마우스를 잡지 않도록 조작권을 한 곳에만 줍니다. 답변이 끝나면 바로 반납합니다.

🛡️

안전 장치

Claude 앱 창 자체는 조작하지 않고, 결제·삭제·전송처럼 되돌리기 어려운 동작은 실행 전에 먼저 물어봅니다.

🔄

관리 창 · 자동 업데이트 확인

시작 메뉴 핸드파일럿 관리에서 상태 점검·설정·로그를 보고, 새 버전은 [지금 설치] 버튼 하나로 받습니다.

2준비물
Windows PC 한 대마다 한 번씩 설치합니다. (핸드파일럿은 설치된 그 PC의 화면만 조작합니다)
Windows 10 / 11Windows 10 2004 이상. Mac은 지원하지 않습니다.
Claude 데스크톱 앱직접앱을 설치하고 Code 탭을 한 번 열어 두세요. 그때 Claude Code가 앱 안에 함께 설치됩니다.
GitHub 로그인직접핸드파일럿 저장소는 비공개라 처음 내려받을 때 로그인 창이 뜹니다. 접근 권한이 있는 계정으로 본인이 직접 로그인하세요.
Git자동코드를 받고 업데이트할 때 씁니다. 없으면 설치 파일이 설치합니다(Windows가 권한을 물으면 [예]).
Python · 라이브러리자동없으면 설치 파일이 설치합니다(무료, 관리자 권한 불필요).
3설치
설치 파일 하나를 받아 더블클릭하면 끝입니다. 중간에 할 일은 GitHub 로그인 한 번뿐입니다.
⬇설치 파일 받기
핸드파일럿-설치.cmd (1KB) — 받은 파일을 더블클릭하세요.
① 받기② 더블클릭③ GitHub 로그인④ "설치 완료!"

  1. 설치 파일 받기 → 더블클릭

    검은 설치 창이 열리고 자동으로 진행됩니다. Claude 앱 확인 → Git(없으면 설치) → 핸드파일럿 내려받기 → Python·라이브러리 → Claude Code에 등록 → 시작 메뉴 핸드파일럿 관리 바로가기까지 만듭니다.

    ⚠️
    처음 보는 파일이라 경고가 나올 수 있습니다. 브라우저가 묻으면 [유지], 실행할 때 "게시자를 확인할 수 없습니다"면 [실행], 파란 "Windows의 PC 보호" 창이면 [추가 정보] → [실행], Git을 설치하며 권한을 물으면 [예]를 누르세요.

  2. GitHub 로그인 (처음 한 번)

    "Connect to GitHub" 창이 뜨면 Sign in with your browser를 눌러 로그인하세요. 이 PC에 기억되어 다음부터는 묻지 않습니다(업데이트도 그대로).

  3. "설치 완료!" 확인 → 새 채팅창에서 시험

    마지막에 주간 업데이트 확인(매주 월요일 오전 10시)을 켤지 물어봅니다 — Enter면 켜집니다. 그다음 Claude 앱에서 새 채팅창(Code 탭)을 열고 입력해 보세요. 스크린샷이 돌아오면 성공입니다.

    /handpilot:handpilot 지금 화면 봐줘
ℹ️
Claude 앱의 Code 탭을 한 번도 안 열었다면 설치 창이 기다리며 안내합니다. 앱에서 Code 탭을 연 뒤 설치 창으로 돌아와 Enter를 누르세요. 이미 열려 있던 채팅창에는 핸드파일럿이 안 보일 수 있습니다 — 새 채팅창을 열거나 앱을 트레이에서 완전히 종료 후 다시 실행하세요.
다른 방법: PowerShell에 한 줄 붙여넣기
파일을 받기 어려우면 시작 메뉴에서 Windows PowerShell을 열고 붙여 넣으세요. 설치 파일과 똑같이 진행됩니다.
iwr -useb https://gobong-choi.github.io/Gobongs/handpilot/setup.ps1 -OutFile "$env:TEMP\handpilot-setup.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\handpilot-setup.ps1"
직접 하나씩 설치 (고급)
Git이 있고 GitHub에 로그인돼 있다면, 원하는 폴더에 받아서 설치 스크립트를 실행해도 됩니다(폴더 위치·이름 자유, 한글·공백 가능).
git clone https://github.com/Gobong-Choi/handpilot.git "$env:USERPROFILE\handpilot"
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\handpilot\install.ps1"
4사용법
채팅창에서 평소처럼 말로 시키면 됩니다. "핸드파일럿"이라는 말을 넣거나 /handpilot:handpilot으로 시작하면 확실합니다.

핸드파일럿으로 크롬에 열린 표에서 합계 숫자 읽어줘
💡
작업할 프로그램을 최대화해 두면 Claude 채팅창의 변화가 섞이지 않아 더 빠르고 정확합니다.

작업 중에는

  • 화면 구석에 작동 중 표시창이 뜹니다(스크린샷에는 찍히지 않음).
  • 마우스·키보드를 만지면 일시정지 → 표시창의 [재개](이어서 하기) 또는 [종료](이 작업 끝내기).
  • [재개]·[종료]는 사람이 실제로 클릭해야만 눌립니다.
  • 다른 채팅창이 쓰는 중이면 "사용 중" 안내가 나오고 기다립니다.
▶ 핸드파일럿 작동 중
⏸ 일시정지 재개종료
⚠️
Claude가 보는 화면은 Claude(Anthropic)로 전송됩니다. 고객 개인정보·비밀번호가 보이는 화면에서는 쓰지 않거나, 필요한 창만 띄워 두세요. 비밀번호 입력·결제·송금·삭제는 Claude가 먼저 확인을 받습니다.
5업데이트
새 버전은 버튼으로 설치합니다. 설치 시점은 항상 내가 고릅니다(자동으로 설치되지 않음).

버튼으로 (권장)

  • 시작 메뉴 핸드파일럿 관리 → 상태 탭 → [업데이트 확인]
  • 새 버전이 있으면 바뀐 내용과 함께 설치 창이 뜹니다 → [지금 설치]
  • 주간 확인을 켜 두면 매주 월요일 오전 10시에 새 버전이 있을 때만 설치 창이 뜹니다. 핸드파일럿이 작업 중이면 끝난 뒤에 뜹니다.
  • 새 버전이 있으면 채팅창 결과에도 한 줄 안내가 붙습니다.

명령으로

설치한 폴더의 update.ps1을 실행합니다.

# 새 버전이 있는지만 확인 powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\handpilot\update.ps1" -Check
# 받아서 적용 powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\handpilot\update.ps1"
ℹ️
적용 시점: 동작·설정은 바로 / 실행 중인 채팅창은 10분 쉬면 새 코드로 자동 교체 / 새 도구·사용설명서는 새 채팅창부터.
6문제 해결
먼저 핸드파일럿 관리 → 상태 탭(또는 설치 폴더의 doctor.ps1)으로 점검하세요. 문제 항목과 해결 방법을 알려 줍니다.
증상이렇게 하세요
새 채팅창에서 핸드파일럿이 안 보임Claude 앱을 트레이에서 완전히 종료 후 다시 실행. 그래도 없으면 설치 파일을 한 번 더 실행(여러 번 실행해도 안전)
모든 동작이 "일시정지"로 거부됨화면 구석 표시창에서 [재개](이어서) 또는 [종료](끝내기)를 직접 클릭
"다른 채팅창이 핸드파일럿을 사용 중"그 채팅창의 답변이 끝나면 자동으로 풀립니다. 일시정지 상태라면 표시창에서 [재개]/[종료]
글자 입력이 "Claude 앱이라 막았습니다"로 거부됨맨 앞 창이 Claude 앱입니다. 작업할 창을 작업 표시줄에서 앞으로 가져온 뒤 다시 시키세요
클릭 위치가 어긋남해상도·배율을 바꾼 직후일 수 있습니다. "전체 화면 다시 보고 해줘"라고 시키세요
업데이트 설치 창의 [지금 설치]가 회색이 PC에서 프로그램 파일을 직접 고친 상태입니다. PC 전용 설정은 관리 창 설정 탭(config.local.json)에 저장하세요
설치 창에서 "내려받기 실패"저장소 접근 권한이 있는 GitHub 계정으로 로그인했는지 확인. 다른 계정으로 로그인했다면 Windows 자격 증명 관리자 → Windows 자격 증명에서 git:https://github.com을 지우고 설치 파일을 다시 실행
설치 파일을 더블클릭해도 창이 바로 닫힘위의 "PowerShell에 한 줄 붙여넣기" 방법으로 설치하면 오류 내용이 창에 남습니다
