📖사용 가이드 — 매년 작업 순서
1
LS증권 HTS에서 거래내역 다운로드
HTS → 거래내역 조회 → 기간 설정 → 엑셀 저장
파일명 예시: ls증권_2025_거래내역.xlsx
2
① 파일 업로드 탭에 파일 드래그
여러 연도 파일을 한 번에 올릴 수 있습니다. 중복 기간 감지 경고가 표시됩니다.
3
② 데이터 검증 탭 확인
7가지 항목이 자동 체크됩니다. 빨간 오류는 반드시 수정, 노란 경고는 의도한 거래인지 확인하세요.
4
③ 손익 계산 탭에서 방법 선택
FIFO 또는 이동평균 중 세무사와 협의한 방법으로 선택하세요.
한 번 선택한 방법은 매년 동일하게 유지해야 합니다.
5
④ 위하고 전표 탭 → 전표 입력
클립보드 복사 후 위하고 전표입력 화면에 붙여넣기, 또는 ⑦ 다운로드에서 엑셀로 받아 사용하세요.
6
⑤ 잔고 현황 탭 → 연말 잔고 보관
연도 마감 전 ⑦ 다운로드 → 잔고현황 .xlsx를 저장해 두세요. 다음 해 기초잔고 관리에 사용됩니다.
